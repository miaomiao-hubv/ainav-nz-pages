📊 XLSX Format Info

XLSX (Office Open XML) is the standard Excel format since 2007. It stores data in worksheets with cells, formulas, and formatting. This tool extracts raw cell values and converts them to your chosen format.

🇳🇿 NZ Data Format Standards

  • CSV exports use UTF-8 encoding with BOM for Excel compatibility
  • Date formats follow NZ standard: DD/MM/YYYY
  • Numbers use decimal point (not comma) notation
  • JSON output uses arrays of objects with header keys
