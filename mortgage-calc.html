📘How Mortgages Work in NZ

In New Zealand, most home loans use a table mortgage structure — equal repayments with decreasing interest and increasing principal components over time.

📐Amortization Formula

M = P × r(1+r)^n / ((1+r)^n − 1)

P = principal, r = periodic rate, n = number of payments

🏦Mortgage Types in NZ

  • Table mortgage: Equal payments, decreasing interest
  • Reducing mortgage: Equal principal, decreasing payments
  • Interest-only: Pay only interest for a set period
  • Fixed vs floating rate options available
