📘How FBT Works

Fringe Benefit Tax (FBT) is paid by employers on non-cash benefits provided to employees, such as company vehicles. The tax is calculated on the taxable value of the benefit using either the cost-price method or the tax-book value method.

📐Key Formulas

Cost-Price Method:

Taxable = 5% × GST-Incl Cost × Days / 365

Tax-Book Value Method:

Taxable = 9% × Book Value × Days / 365

FBT Payable:

FBT = Net Taxable Value × FBT Rate

💡FBT Rates

  • 63.93% — Single rate (income > $69,156)
  • 49.25% — Alternate rate (income ≤ $69,156)
  • Employee contributions reduce the taxable value
  • FBT is filed quarterly with IRD
