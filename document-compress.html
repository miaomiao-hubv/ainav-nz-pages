📁 DOCX Structure

A DOCX file is actually a ZIP archive containing XML files and media. Compression works by finding embedded images and re-encoding them at lower quality. The text content remains untouched.

💡 Compression Tips

  • PDFs with images compress best — text-only files see modest gains
  • DOCX compression targets embedded images only
  • "High" compression may noticeably reduce image quality
  • For scanned PDFs, expect the largest file size reduction
